# TwirlWord public pages

Static marketing, support and privacy pages for the TwirlWord beta. This repository contains only public website content.

Render Static Site settings:

- Root directory: `site`
- Build command: `python3 check_site.py`
- Publish directory: `public`
- Automatic deployment: off

Run `python site/check_site.py` to check local links and assets. Public routes are `/`, `/support/`, and `/privacy/`.
